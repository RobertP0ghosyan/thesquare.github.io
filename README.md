# The Square · Yerevan — concept website

Static, responsive concept for The Square Restaurant & Bar at Armenia Marriott Hotel Yerevan.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the **root `index.html`** file. It is self-contained, including the photography.
2. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
3. Open the Pages URL shown by GitHub.

The `dist/` folder is an editable version with separate image files. If uploading that version instead, put the *contents* of `dist/` at the repository root.

## Content notes

- This is a proposal, not an official website. Marriott currently lists **The Square Restaurant & Bar** and **Armenia Brasserie Restaurant** as separate dining venues. The Square is the main focus because the Instagram account supplied for this project belongs to The Square.
- Hours and phone numbers were checked against the [Marriott dining page](https://www.marriott.com/en-us/hotels/evnmc-armenia-marriott-hotel-yerevan/dining/) on 31 October 2026. Confirm them with the venue before official launch.
- The gallery contains a fixed selection of images from [@thesquare_marriott](https://www.instagram.com/thesquare_marriott/), with links to the original posts. It does not update automatically. Confirm image reuse rights with the venue before making the site public.
- The page uses Google Fonts; it falls back to local fonts if they are unavailable.
